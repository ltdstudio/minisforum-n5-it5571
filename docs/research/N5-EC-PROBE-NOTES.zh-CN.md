# Minisforum N5 EC 探测记录（2026-08-04 更新：BIOS 逆向突破）

> **2026-08-08 纠错：**旧反汇编器会丢失 `MOV DPTR,#imm16` 的低字节，导致本文把 `0x96xx` 误写为 `0x96`。因此“XDATA 0x96 是内部 PWM 执行寄存器”及据此得到的内部地址解释无效；`EC RAM 0x34` 的实机控制结论仍有效。修正后已确认硬件 PWM 基址为 `0x1800`，三路 RPM 可通过 PMC2 命令 `0x14-0x19` 读取。完整新结论见本次成果 `N5-PWM-RPM接口逆向.md`。

> 目标：破解 ITE IT5571 EC，让 N5 在 Unraid 下实现风扇自动控制

## 一、实机测试结论（双向验证，铁证）

| 操作 | CPU 温度变化 | 结论 |
|---|---|---|
| 写 ACPI EC RAM `0x34 = 0x00`（停转） | 43.4 → 47.8 → **48.9°C**（+5.5°C） | ⛔ 风扇停转生效 |
| 写 `0x34 = 0x64`（全速） | 48.9 → **44.6°C**（-4.3°C） | ✅ 全速生效 |
| 写 `0x37 = 0x00` | CPU 稳定（43.6°C） | ❌ 非 CPU 风扇控制（排除） |
| 写 `0x38 = 0x00` | CPU 稳定（44°C） | ❌ 排除 |

**ACPI EC RAM 0x34 = PWM 占空比设定寄存器（主机可写，直接控制风扇）**

## 二、BIOS 固件逆向（重大突破）

### 提取路径
1. 官网下载 `F8NAA_HPT_1.04_250902.zip` → `F8NAA.BIN`（32MB）
2. Release_Note 确认：**EC 版本 0.14**（BIOS 1.04，2025-09-02）
3. EC 固件 = BIOS 文件 **偏移 0x0 起的 64KB 8051 镜像**（无压缩，明文）
   - 特征：`02 00 70`（8051 LJMP 复位向量）、`UUCMXG_EC-V14.6`、`Project:F8NAA_StrixHowk`、`ECVer:00.00.00.0E`、`Aug 13 2025`
4. 反汇编：`mcs51-disasm`（C 编译）→ 41881 行汇编

### 固件内部寄存器架构（XDATA 空间）
| 地址 | 功能 | 代码证据 |
|---|---|---|
| **XDATA 0x96** | **内部 PWM 执行寄存器** | 写 0xFF=全速(`0xe010`)、写 0x00=停(`0xf464`)、最小钳位 0x20(`0x1af6`)、PID 递增(`0x178f`) |
| XDATA 0x95 | 温度/PWM 相关 | `0x2a69` 读后 +0x64(100)、`0x2adf` 读判断 |
| XDATA 0x76 起 | **风扇曲线表（3 字节/项）** | `0xf309`: 索引×3+0x76 → 对应 EC RAM 0x70-0x81 |
| XDATA 0x10-0x44 等 | 状态/控制寄存器 | 大量 movx 访问 |
| 0x4380 起 | 查表数据区 | `0xe2a9`: ×14+0x4380 |

### 风扇曲线表解码（EC RAM 0x70-0x81）
```
0x70-0x72: {0C 22 00}   → 温度点 12°C → PWM 34%
0x73-0x75: {10 64 22}   → 温度点 16°C → PWM 100%
0x76-0x78: {10 64 64}   → 16°C → 100%（封顶）
（0x79-0x81 重复同模式 = 第二通道曲线）
```
3 字节/项 × 3 点 × 2 通道 = 18 字节 ✓ 与 0x70-0x81 完全吻合

### 控制链路（完整理解）
```
主机写 ACPI EC RAM 0x34 (PWM设定)
  → 固件每周期读取
  → 应用最小钳位 (0x20=20%)
  → 写入内部 XDATA 0x96 (硬件 PWM)
  → 风扇转速变化
```

## 三、BIOS 风扇转速数据（用户问题：2498/2234/1141 RPM 在哪）

- BIOS 的 CPU/SSD/HDD Fan Speed 来自 **IT5571 TACH 硬件计数器**（datasheet: F1TLRR/F1TMRR/F2TLRR 等寄存器）
- **不在标准 ACPI EC RAM 256 字节内**（实测 dump 无 RPM 值）——固件通过 XDATA 高地址/TACH 捕获寄存器读取（代码中 0x19 寄存器写入 0x80/0x82 疑似 TACH 捕获控制 @0xE5B0）
- 主机要读 RPM 需访问 XDATA 扩展空间（非标准 ACPI 命令），暂未找到直接通道
